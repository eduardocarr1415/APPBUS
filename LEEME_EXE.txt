SISTEMA DE GESTION - COMPANIA DE BUSES (version ejecutable)
==========================================================

No necesita instalar Python ni tener Internet.

INSTALACION EN EL PC
1) Copie esta carpeta a una ubicacion con permiso de escritura,
   por ejemplo C:\BusGestion  o  Documentos\BusGestion.
   (NO la ponga en C:\Archivos de programa: alli no se puede guardar la base.)
2) Doble clic en BusGestion.exe. Se abre una ventana negra y luego el navegador
   en http://127.0.0.1:8000
3) Usuario: admin   Contrasena inicial: Admin12345678!
   Cambiela en "Mi perfil" despues del primer ingreso.
4) NO cierre la ventana negra mientras use el sistema. Cerrarla apaga el sistema.

Si Windows muestra "Windows protegio su PC": clic en "Mas informacion" > "Ejecutar de todas formas".

DONDE ESTAN LOS DATOS
- La base de datos se crea en la carpeta  instance\buses.sqlite3  junto al .exe.
- Las fotos y archivos subidos quedan en  instance\uploads\
- Para actualizar el programa, reemplace SOLO BusGestion.exe; no borre la carpeta instance.
- Para llevar los datos de otro PC, copie su carpeta instance junto al .exe.

COMANDOS (abra una ventana CMD en esta carpeta)
  BusGestion.exe demo          Carga datos ficticios de demostracion
  BusGestion.exe backup        Copia de seguridad en la carpeta copias_seguridad\
  BusGestion.exe reset-admin   Restablece la contrasena de admin

Haga copias de seguridad periodicas y guardelas fuera del PC (USB, nube).
